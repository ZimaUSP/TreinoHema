# Atividade introdutória de robótica móvel hospitalar

Este diretório reúne o material didático e o projeto executável da atividade.

## Documentos

- [`TUTORIAL_ALUNO.md`](TUTORIAL_ALUNO.md): roteiro passo a passo destinado aos alunos;
- [`GABARITO_INSTRUTOR.md`](GABARITO_INSTRUTOR.md): soluções, respostas e orientações de aplicação.

## Projeto

O workspace completo está em:

```text
hospital_webots_ws/
```

Leia [`hospital_webots_ws/README.md`](hospital_webots_ws/README.md) para instalar
dependências, compilar e executar cada experimento.

O projeto contém:

- um modelo editável do robô em `PROTO`;
- um mundo introdutório sem ROS 2;
- controlador nativo Python;
- dois mundos hospitalares;
- plugin do `webots_ros2_driver`;
- missões ROS 2 completas;
- templates incompletos para distribuição aos alunos;
- validação estática dos arquivos.
